# Навигация по командной строке

## P.S Данная лаба выступает в роли примера, последующие выполнены с целью освоения конкретных инструментов.

## Цель
Научиться определять текущую папку и перемещаться между папками.

## Задания
1. Узнать текущую папку.
2. Перейти в домашнюю папку.
3. Вернуться в предыдущую папку.

## Моё решение

```bash
pwd
cd ~
cd -
```

## Проверка
Вывод `pwd` после каждого перемещения

## Ошибки и выводы
Базовая навигация освоена.
